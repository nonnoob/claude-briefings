# 🛠️ 开发工具更新简报 · 2026-07-26

## Claude App 更新

- Claude Opus 5 发布并成为 Claude Code 默认 Opus 模型：原生 1M 上下文窗口，fast mode 定价 $10/$50（每 Mtok），Opus 4.7 同时移出 fast mode。来源：[Claude Code Changelog v2.1.219](https://code.claude.com/docs/en/changelog)（2026-07-24）
- 同一版本（v2.1.219）将子代理（subagent）默认最大嵌套深度从 1 层提升到 3 层，可用 `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` 调整。来源：[Claude Code Changelog](https://code.claude.com/docs/en/changelog)（2026-07-24）
- v2.1.220 发布，仅含稳定性与可靠性修复，无新功能。来源：[Claude Code Changelog](https://code.claude.com/docs/en/changelog)（2026-07-25）
- Claude 语音模式（Voice Mode）扩展至 Opus、Sonnet 模型（此前仅 Haiku），支持语言增至 11 种，并与 Gmail、Google Calendar、Slack 等已连接工具打通。来源：[MacRumors](https://www.macrumors.com/2026/07/24/claude-voice-mode-opus-sonnet-model-support/)（官宣日期各报道口径不一，落在 7/23–24，判断为本期窗口边缘，酌情收录）

运行备注：首次运行，按过去 48 小时窗口处理；本期 VSCode、生态与社区动向两个板块未检索到窗口内的实质新内容，已省略；语音模式一条发布时间处于窗口边缘（7/23–24），已收录并注明假设。
