# 🛠️ 开发工具更新简报 · 2026-07-30

## VSCode 更新

- VS Code 1.131 正式版发布：新增子代理（subagent）状态可视化，无需展开对话即可查看运行中子代理的模型、耗时和当前工具调用；新增实验性内置听写功能，无需安装 Speech 扩展即可在聊天、编辑器和终端中语音输入；新增实验性混合 Markdown 编辑器，可在 Agents 窗口中直接编辑 Markdown 并添加供 agent 处理的评论。来源：[VS Code 1.131 Release Notes](https://code.visualstudio.com/updates/v1_131)、[Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/07/29/vs-code-1-131-adds-built-in-dictation-hybrid-markdown-editing-and-subagent-status.aspx)

（Claude App 更新、生态与社区动向本期覆盖窗口内无实质新内容，两节省略。）
