# 任务特有的追加必须有 ADR：以股市复盘简报的判断记录为首例

> 补充 ADR-0001 与模板装配说明：模板规定运行记忆固定三节、条目"一句话讲清楚"、行为定义只有 SKILL.md 一个文件。自本决策起，单个任务可以在有记录的前提下偏离这三点。

`stock-market-briefing` 在三处偏离模板，全部保留：

1. **运行记忆多一节"判断记录"**：待评判断、累计命中统计、最近 20 条已评判断。
2. **条目可以是一段而不是一句话**：深度归因条目按"催化剂、传导、预期差、佐证"四段写在同一行，约 150–250 字；仍是 `- ` 开头的单行、仍以 `来源：` 结尾，格式契约里看门狗校验的部分一条没动。
3. **任务目录里带一个辅助脚本 `quotes.py`**：只取行情数字，不含任何判断规则。

决策依据（2026-11-23）：读者要的是"为什么涨跌"而不只是"涨跌了什么"，并且明确不要马后炮。事后归因随手就能编圆，从产出上看不出对错；唯一能检验它的办法是让每一期对下一个交易日给出判断、下一期如实评判。这需要跨运行保存待评判断和基准收盘价——它既不是已报条目（不参与去重），也不是进行中事件（有上限、会因无进展被移出），放进前三节的任何一节都会被那一节的规则误伤，所以单独成节。

行情数字不靠检索：检索摘要里的价格常是盘中值或旧值，而归因和评判都建立在涨跌幅上。实测腾讯行情接口一次请求覆盖三地市场，Yahoo 的日线接口补量比和近期收盘价；用脚本取数比让模型每次解析 `~` 分隔的原始字段可靠。关注列表仍只写在 SKILL.md 里，脚本不持有副本。

## Consequences

- 模板装配说明加了一句：任务特有的追加只在有 ADR 记录时保留。以后"严格按模板修改"某个任务时，凭这份记录保留上述三处，其余照模板还原。
- 行为定义仍只有 SKILL.md 一份（ADR-0004 不变）：脚本里没有门槛、没有命中规则、没有关注列表，改行为不需要改脚本。
- 运行记忆损坏时，待评判断可以从最近一份归档的"下一交易日展望"重建，累计命中统计不能，只能从零重新累计——这是把统计放在记忆里而不是归档里的代价，可以接受：归档里每期都有当期的累计数字，人工可以回查。
- 看门狗新增 `WEEKDAYS_PM` 一类（周一至周五下午运行，周末不要求归档）。各市场是否休市由运行时按行情时间判定，不进调度配置；三地同时休市的工作日照常落一份空期归档。
- 简报里的判断公开在阅读站上，所以"下一交易日展望"板块固定带一句"不构成投资建议"的声明，且不写仓位、买卖指令和自拟目标价。
- 两个行情接口都是未公开承诺稳定性的公共接口。失效时脚本对应列输出 `n/a`，任务按 SKILL.md 降级为直接请求或检索；连续多期取不到数字时应换数据源，而不是放宽"数字不从检索摘要里抄"这条规则。
